## The prompt locks a file, not a paragraph

There is no TikTok mode in the xAI image or video docs, and there is no video prompting guide. `https://docs.x.ai/developers/model-capabilities/video/prompting-guide.md` returned 404 on 14 October 2026, and `llms.txt` lists video generation, image-to-video, and reference-to-video, not a video prompt page ([llms.txt](https://docs.x.ai/llms.txt)). The image guide, sitemap last modified 8 October 2026, is the stills authority. For `grok-imagine-image-2.0` it wants one photograph in prose, subject first, four to six sentences. The order to keep across a series is the subject, then details and the focal point, then art direction, then light, then subject colors and background colors as separate fields, then the crop: what the frame cuts off, what stays sharp, one scene. Name materials physically. State a count. Pair a constraint with the thing you want. A long avoid list is easy to ignore, and it spends the prompt on objects that then show up. “Slightly underexposed” and “crushed shadows” pull the picture dark. Leave out chromatic fringing, dust, and scratches. A line that reads like an instruction still has to describe an attribute of that single picture, because a generation has no before-and-after. A prompt that leads with mood, film stock, or a pile of things to avoid produces a styled stand-in ([Image Prompting Guide](https://docs.x.ai/developers/model-capabilities/images/prompting-guide)).

Generate when there is no picture, or when the subject is the wrong object, a key element is missing, or the count is off. Edit when the subject and the layout are already right and one to three details must change. Lead with those changes. Follow with one sentence that keeps the same subject, angle, crop, and prop placement. The guide’s own edit shape is the watch-strap sentence: name the replacement, then keep the wrist, the cuff, the angle, and the desk. An edit that opens with “keep everything” barely moves. An edit that pastes in a full new prompt restages the scene. If a fix misses, change the words and point at the part. Do not repeat “more realistic.” On the next pass, change only the detail that failed. Multi-image edit accepts up to five sources, and the output follows the first image’s aspect ratio unless the request overrides it. The multi-image page does not document `<IMAGE_0>` tokens for stills. Do not depend on those tokens to composite a face from one still and a place from another ([Image Editing](https://docs.x.ai/developers/model-capabilities/images/editing); [Multi-Image Editing](https://docs.x.ai/developers/model-capabilities/images/multi-image-editing)).

The ratio, the resolution, and the quality sit on the request, not inside the prose. For this poster set `aspect_ratio` to `9:16`, `resolution` to `2k`, and `quality` to `medium`. Omitted ratio defaults to `auto`. `quality` accepts `low`, `medium`, or `auto`, and **`auto` currently serves `low` on generation and `medium` on edit**. Pin `medium` when the face has to stay recognizable. The generation page does not state pixel width and height for a `2k` 9:16 still. Do not assume the still is 1080 by 1920 ([Image Generation](https://docs.x.ai/developers/model-capabilities/images/generation); [Image Prompting Guide](https://docs.x.ai/developers/model-capabilities/images/prompting-guide)). The current image slug is `grok-imagine-image-2.0`. A release-notes line dated **2 November 2026** says `grok-imagine-image-quality` is retired onto that slug at `quality: low`, and that `grok-imagine-image` 1.0 is not affected. That date is after 14 October 2026. Do not treat the retirement as something that has already happened. The model to name for this week is `grok-imagine-image-2.0`. The August notes, which are before the cutoff, are the ones already visible in the prompting guide: the quality default moved to `auto`, and edit sources rose from 3 to 5 ([grok-imagine-image-2.0](https://docs.x.ai/developers/models/grok-imagine-image-2.0); [Release Notes](https://docs.x.ai/developers/release-notes)).

The CLI names map straight onto those docs. `image_gen` is generate. `image_edit` is the edit call. `reference_to_video` is reference-to-video, which is what a loop and a start-and-end pin actually are. Image-to-video is a different docs mode: one still becomes the first frame, the prompt says what happens next, and the clip can be native 1080p. Sending `image` together with `last_frame`, keyframes, or reference images switches the request into reference-to-video. On `grok-imagine-video-1.5` that mode stops at **720p**. Native 1080p and a pinned end are not available on the same request. Lite can upscale image-to-video to 1080p and cannot pin frames. For a master that needs the end pose to match a second still, accept the 720p pin and scale it in the edit. For a master that only needs one camera move from a locked opening, stay on image-to-video at 1080p and do not send `last_frame` ([Video Overview](https://docs.x.ai/developers/model-capabilities/video/overview); [Reference-to-Video](https://docs.x.ai/developers/model-capabilities/video/reference-to-video); [Image-to-Video](https://docs.x.ai/developers/model-capabilities/video/image-to-video)).

Video defaults will wreck a vertical insert if they are left alone. Duration is 1–15 seconds and **defaults to 8**. Aspect ratio **defaults to 16:9** on text-to-video. Resolution choices are 480p, 720p, and 1080p, and **480p is the documented default**. Image-to-video ignores `aspect_ratio` and copies the still, so the still has to be 9:16 already. A 6-second insert must set `duration` to 6. Text-to-video must also set `aspect_ratio` to 9:16. Plain image-to-video that should be sharp sets `resolution` to 1080p. The docs do not state the exact pixel size behind the 1080p or 720p labels. Clips on all three models are 1–15 seconds. Use `grok-imagine-video-1.5` when the clip needs a pin, a reference, or native 1080p. ## Four paste-ready prompts keep the name out of Grok

Use the approved still as the image input for the edit and for both video prompts. Do not regenerate him from text to “refresh” the face.

### image_gen builds the canonical still

`image_gen` is the docs’ generate call on `grok-imagine-image-2.0`. Set `aspect_ratio` to `9:16`, `resolution` to `2k`, and `quality` to `medium`. Paste only the prose. Do not put “9:16” inside it.

```text
A vertical poster photograph of one fictional man standing on pale Greek stone at night, weight on his back foot, one hand lifted as if he is about to turn. He has salt-and-pepper wavy hair, a full beard, warm skin, a calm confident face, and a cream toga worn over a dark shirt. Neon cyan and neon purple light the stone from the city behind him, while the ground and the sky stay deep navy. A broad flat cream panel fills the lower third, bare and even, with the man fully visible above it. Hard neon rim light from camera-right leaves his face bright enough to read, in one tall scene cropped from head to feet.
```

Approve one result. That file is the identity. Hands and feet are inside the frame because the later clip has to move them. The cream panel stays bare so the studio can set SMOKRATES in type.

### image_edit moves place and pose

`image_edit` is the docs’ edit call, `POST /v1/images/edits` on `grok-imagine-image-2.0`. Set `image` to the approved still, `aspect_ratio` to `9:16`, `resolution` to `2k`, and `quality` to `medium`. Pose plus place is two changes, inside the one-to-three-detail rule, only while the face and the layout are already right.

```text
Move him to the edge of dark water in the same night city, and turn his torso three-quarters toward the camera while his feet stay planted. Keep the same face, the same salt-and-pepper wavy hair, the same full beard, the same warm skin, and the same cream toga over the dark shirt. Keep the same tall crop and the same bare cream panel in the lower third. Neon cyan and neon purple stay on the water, the ground stays deep navy, and the light still reads on his face.
```

If the edit restages the face, the city, or the panel, change the missed clause and run the edit again from the approved still. Do not paste the first prompt back in.

### The six-second turn is a pin at 720p, or a description at 1080p

The prose is one motion. It names the start place and the end place. The water, the city, and the cream panel do not move. There is no soundtrack sentence, because the dub is added in the edit and the clip should be silent.

```text
At the start he stands in profile on the left third, looking out over the dark water, both arms at his sides. He turns only his head and shoulders until he faces the camera, and one hand rises from his side to shoulder height. At the end he is still on the same stone, now nearer the center, facing forward. The water, the city, and the cream panel do not move.
```

When the end pose must match a second still, this is `reference_to_video`. Edit that end still from the same scene first, with `image_edit`, so only the pose changes. Then send `image` as the start still and `last_frame` as the end still on `grok-imagine-video-1.5`, with `duration` 6, `resolution` `720p`, and `generate_audio` false. The pins hold the ends. The four sentences only steer the middle. Reference-to-video on this model is up to 720p, not native 1080p. Scale the clip in the edit if the master is 1080 wide.

When the end only has to be described, do not send `last_frame`. That request is the docs’ image-to-video, not reference-to-video. Send the edited still as `image` only, `duration` 6, `resolution` `1080p`, and `generate_audio` false. Do not send `aspect_ratio`. It is ignored, and the still’s ratio is the ratio. The end position is then a description, not a pin. If the CLI’s only video tool is `reference_to_video`, use the 720p pin path. Do not add `last_frame` to a 1080p request and expect both.

### reference_to_video loops the same still

`reference_to_video` on `grok-imagine-video-1.5`. The same approved still is both `image` and `last_frame`. Set `duration` to 6, `resolution` to `720p`, and `generate_audio` to false. Day 2 can use this clip as the whole post only when the seam is clean and the studio adds no spoken intro. Otherwise it is an insert, or the day is skipped.

```text
A thin ribbon of cyan smoke leaves his raised hand, travels once in a slow circle in front of his chest, and returns to that same hand. His face, his feet, and the night city stay still. The pose at the end is the pose at the start, above the same bare cream panel.
```

The duplicated frame is the loop. The sentence is there so the smoke leaves and comes back instead of wandering off. Do not ask the model to paint a title, a counter, or the smoke as a caption.
